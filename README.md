# 메모 자동기록 (MemoAutoRecorder)

개인용 Android 자동화 앱입니다.

## 목표 동작
1. 지정한 메모 앱이 화면에 나타나면 접근성 서비스가 이를 감지합니다.
2. Android 빠른 설정을 열고 `AI 기록` 타일을 찾아 클릭합니다.
3. 1~2초 후 앱 자체 녹음기를 포그라운드 서비스로 시작합니다.
4. 녹음은 백그라운드에서 계속되며 `Recordings/MemoAuto` 폴더에 M4A로 저장됩니다.
5. 메모 앱을 벗어난 뒤 설정한 시간(기본 60초) 안에 돌아오면 녹음을 유지합니다.
6. 설정 시간이 지나도록 메모 앱으로 돌아오지 않으면 녹음을 종료합니다.

## 최초 설정
- 앱에서 메모 앱 선택
- 마이크 권한 허용
- `다른 앱 위에 표시` 허용 (Android의 백그라운드 화면 실행 제한을 우회하기 위한 사용자 승인)
- 접근성 설정에서 `메모 자동기록 자동화` 켜기
- 배터리 최적화 제외 권장
- 빠른 설정 타일 명칭이 다르면 기본 `AI 기록` 값을 수정
- 자동화 사용 ON

## Android 14~16 관련
마이크는 while-in-use 권한이므로 백그라운드에서 바로 microphone foreground service를 새로 시작할 수 없습니다. 이 프로젝트는 자동 감지 시 매우 작은 투명 Activity를 잠깐 표시한 다음 녹음 서비스를 시작하도록 설계했습니다. `다른 앱 위에 표시` 권한이 필요한 이유입니다.

## 주의
- 빠른 설정 타일이 접근성 트리에 노출되지 않는 기기에서는 자동 클릭이 실패할 수 있습니다.
- `AI 기록` 기능이 마이크를 독점하는 기기에서는 두 번째 녹음 스트림이 무음이 될 수 있습니다. 앱의 `15초 녹음 테스트`로 확인하세요.
- 이 앱은 개인 사이드로드용으로 설계했습니다. 접근성 API를 일반 자동화에 사용하는 앱은 Google Play 배포 정책상 별도 검토가 필요합니다.

## 빌드
Android Studio에서 폴더를 열고 `app` 모듈을 빌드하세요. 외부 라이브러리는 사용하지 않습니다.
