# 메모 자동기록 V2 (MemoAutoRecorder)

회의 중 지정한 메모 앱을 열면
1. 빠른 설정의 **AI 기록** 타일을 켜고(꺼져 있을 때만),
2. 앱 자체 녹음(M4A/AAC)을 시작하고,
3. 메모 앱을 벗어나 정해진 시간(기본 60초) 안에 돌아오지 않으면 녹음을 끝내고 저장하는
개인 사이드로드용 Android 앱입니다. (대상: Lenovo Yoga Tab / ZUI, Android 14~16)

- V1 검수 결과: [`docs/REVIEW.md`](docs/REVIEW.md)
- 패키지명: `io.github.forlig85.memoauto` (V1 `com.openai.memoautorecorder`와는 다른 앱입니다. V1은 지워주세요. 둘 다 접근성을 켜면 서로 간섭합니다.)

---

## 1. 설치

### APK 받기 (PC 없이)
1. 폰/태블릿 브라우저에서 **https://github.com/forlig85/myco/releases/latest** 를 엽니다.
2. **Assets** 안의 `MemoAutoRecorder-2.0.N.apk` 를 누릅니다.
3. 다운로드가 끝나면 알림이나 "다운로드" 앱에서 APK를 열어 설치합니다.
   - "출처를 알 수 없는 앱" 경고가 나오면 브라우저(Chrome 등)에 **이 출처 허용**을 켭니다.
   - "Play 프로텍트" 경고가 나오면 **세부정보 > 무시하고 설치**.

모든 빌드는 저장소의 `keystore/memoauto-release.jks` 로 서명되므로 **새 버전을 받아 그냥 덮어 설치**하면 됩니다(기존 앱·설정 유지).

### 접근성 "제한된 설정 허용" (Android 13+ 필수)
브라우저로 받은 APK는 접근성 설정이 회색으로 막혀 있습니다.
1. 설정 > 접근성 > 설치된 앱(또는 다운로드한 앱) > **메모 자동기록 자동화** 를 한 번 눌러 "제한된 설정" 안내를 띄웁니다.
2. 설정 > 앱 > **메모 자동기록** > 오른쪽 위 **⋮** > **제한된 설정 허용** (지문/PIN 확인).
3. 다시 접근성에서 **메모 자동기록 자동화** 를 켭니다.

> 앱 홈 화면의 "접근성 서비스" 항목에 같은 안내가 있습니다.

## 2. 권한

| 권한 | 용도 | 필수 |
|---|---|---|
| 마이크 | 회의 녹음 | 필수 |
| 알림 | 녹음 중 표시, 실패/무음 경고, 완료 알림 | 필수(사실상) |
| 접근성 서비스 | 화면에 보이는 앱 창 판단, 빠른 설정 타일 조작 | 필수 |
| 배터리 사용 제한 없음 | ZUI 백그라운드 종료 방지 | 강력 권장 |
| 다른 앱 위에 표시 | 백그라운드에서 녹음 보조 화면을 띄울 때 차단 완화 | 권장 |

마이크·알림 권한은 홈 화면의 **허용** 버튼 하나로 함께 요청합니다. 두 번 거부하면 Android가 더 이상 묻지 않으므로 앱 정보 > 권한에서 직접 켜야 합니다.

## 3. ZUI 배터리·자동 실행 설정

ZUI는 백그라운드 앱을 적극적으로 종료합니다. 앱 프로세스가 죽으면 접근성 서비스도 같이 끊기고, 녹음 중이었다면 파일이 미완성으로 남습니다. (메뉴 이름은 ZUI 버전에 따라 조금씩 다릅니다.)

1. **배터리**: 홈 화면 "배터리 제한 없음" > 허용. 또는 설정 > 앱 > 메모 자동기록 > 배터리 > **제한 없음**.
2. **자동 실행 / 백그라운드 실행**: 설정 > 앱 > 메모 자동기록(홈 화면 "앱 정보" 버튼) 에서 *자동 실행*, *백그라운드 실행*, *백그라운드 팝업/창 표시* 같은 항목이 있으면 모두 허용.
3. **최근 앱 잠금**: 최근 앱 화면에서 메모 자동기록 카드를 아래로 끌거나 길게 눌러 **잠금(자물쇠)**.
4. 재부팅 후 접근성 서비스가 꺼져 있지 않은지 한 번 확인.

앱이 시스템에 의해 종료되면 다음 실행 때 **로그 탭**에 `이전 종료: …` 로 사유가 기록됩니다.

## 4. 설정 (앱의 "설정" 탭)

| 항목 | 기본값 | 설명 |
|---|---|---|
| 대상 메모 앱 | – | 런처에 보이는 앱 중에서 선택 |
| 메모 앱을 열면 AI 기록 켜기 | 켬 | 빠른 설정 타일 자동 실행 |
| 타일 이름 | AI 기록 | 빠른 설정에 보이는 글자(띄어쓰기 무시) |
| AI 기록 켜짐 표시 창 | com.lenovo.levoice.caption | AI 기록이 켜지면 뜨는 자막 창. 이 창이 보이면 빠른 설정을 열지 않고 "이미 켜짐"으로 처리, 누른 뒤 이 창이 뜨면 켜진 것으로 확인 |
| 타일 상태를 색으로 판단 | 켬 | ZUI의 AI 기록 타일은 켜짐/꺼짐을 접근성으로 노출하지 않음. 패널을 연 상태로 화면을 캡처해 AI 기록 아이콘 영역의 색을 같은 패널의 켜진 타일(자동 회전 등)·꺼진 타일(비행기 모드 등) 평균색과 비교 |
| 색으로도 모르면 마이크 사용으로 판단 | 켬 | 이 앱이 녹음을 시작하기 전에 다른 앱의 녹음이 있으면 AI 기록이 켜진 것으로 봄 |
| 상태를 모르면 누르기 | 끔 | 타일이 켜짐/꺼짐을 노출하지 않으면 누르지 않음(이미 켜진 걸 끄는 사고 방지) |
| 메모 앱을 열면 녹음 시작 | 켬 | 앱 자체 녹음 |
| 녹음 시작 방식 | 자동 | 직접 시작 → Android가 막거나 무음 처리하면 1px 투명 보조 화면으로 재시도 |
| 종료 대기시간 | 60초 | 10/30/60초/사용자 지정(5~3600초) |
| 저장 폴더 | 내장 저장공간/Recordings/MemoAuto | "폴더 선택"으로 다른 폴더 지정 가능 |

파일명: `2026-10-08_1000_회의녹음.m4a` (같은 이름이 있으면 시스템이 ` (1)` 을 붙임)

### 동작 규칙
- **사용 중 판단**: 이벤트 패키지명이 아니라 실제로 화면에 보이는 **앱 창 목록**으로 판단합니다. 키보드, 알림창/빠른 설정(시스템 UI), 이 앱 자신의 창은 무시합니다. 분할 화면·팝업 창으로 메모 앱이 보이고 있으면 "사용 중"입니다.
- **잠금 화면**: 판단 보류(타이머를 새로 시작하지도, 취소하지도 않음). 메모 앱을 연 채로 화면을 잠그면 녹음은 계속됩니다.
- **이탈**: 메모 앱 외의 앱이 보이면 타이머 시작 → 대기시간 안에 돌아오면 취소 → 만료되면 녹음 종료·저장.
- 알림의 **녹음 중지** 로 끄면 세션도 끝나고, 메모 앱을 벗어났다가 다시 열 때 새로 시작합니다.
- 녹음 중 10초 동안 파일이 0 byte면 실패 처리, 입력 음량이 10초간 0이거나 시스템이 녹음을 무음 처리하면 경고 알림을 띄웁니다.
- 저장공간이 20MB 아래로 떨어지면 녹음을 끝내고 저장합니다.

### 회의록 (ChatGPT 공유, OpenAI API 호출 없음)
| 항목 | 기본값 |
|---|---|
| 녹음이 끝나면 ChatGPT 공유 자동 열기 | 켬 |
| ChatGPT 전송 방식 | 물어보고 전송 | 물어보고 전송: 회의가 끝나면 결과 화면에 확인창 → "보내기"를 누르면 ChatGPT 열기·전송까지 자동 / 자동 전송: 묻지 않음 / 직접 전송: 채워만 두고 전송은 직접 |
| 프로젝트명 `{프로젝트}` | 다이렉트 |
| Notion 경로 `{Notion 경로}` | 업무 허브 / 10 과제·프로젝트 (이 아래에서 맞는 분류를 찾거나 새로 만듦) |
| 회의 유형 `{회의 유형}` | 정기 회의 |
| 프롬프트 | 전사 → 회의록(핵심 요약, 주요 논의, 결정사항, Action Item, 리스크, 다음 회의 전 확인사항) → 녹음 내용에 맞는 Notion 분류를 찾아 기존이면 거기에, 없으면 새로 만들어 등록 → 어느 분류에 넣었는지 보고. `{회의 유형}`, `{날짜}`, `{파일명}` 자동 채움 |

흐름:
1. 자동 녹음이 끝나면 **"회의 녹음 완료"** 알림(재생 / 회의록 만들기 / 파일 공유)과 **결과 화면**(재생 / 회의록 만들기 / 파일 공유 / 삭제)이 뜹니다. 앱 화면에서 직접 시작한 테스트 녹음은 알림만 띄웁니다.
2. "자동 열기"가 켜져 있으면 결과 화면이 바로 **ChatGPT 앱**에 녹음 파일 + 프롬프트를 넘깁니다. 프롬프트는 **항상 클립보드에도 복사**되므로, ChatGPT 입력창이 비어 있으면 길게 눌러 붙여넣으면 됩니다.
3. 전송 방식이 "물어보고 전송"이면 먼저 결과 화면에서 확인창이 뜨고, "보내기"를 눌러야 ChatGPT로 넘어갑니다. "직접 전송"이 아니면 접근성 서비스가 ChatGPT 화면을 보고, 입력창에 프롬프트가 없으면 채우고, 첨부 업로드가 끝나 전송 버튼이 활성화되면 **한 번만** 누릅니다. 음성 모드/받아쓰기 버튼은 누르지 않습니다. 못 누르면 알림이 뜨고 로그에 ChatGPT 화면 구조가 남습니다.
4. Notion 등록은 ChatGPT가 프롬프트 지시에 따라 합니다(ChatGPT 계정에 Notion 연결 필요).
5. 백그라운드 제한으로 결과 화면이 안 열리면 "회의록을 만들까요?" 알림으로 대신합니다.
6. ChatGPT 앱이 없거나 공유를 받지 않으면 일반 공유 선택창을 엽니다.

## 5. 테스트 순서

홈 탭의 **테스트·진단** 버튼을 사용합니다. 결과는 모두 **로그 탭**에 시간과 함께 남고, **복사/공유**로 보낼 수 있습니다.

1. 홈 > 준비 항목을 위에서부터 모두 ✓ 로 만들기 (메모 앱 선택, 권한, 접근성, 배터리).
2. **15초 녹음 테스트** → 15초 뒤 "회의 녹음 완료" 알림 → 재생해서 소리가 들리는지 확인.
3. **빠른 설정 진단** → 빠른 설정이 열렸다 닫힘 → 로그 탭에 `===== 빠른 설정 진단 =====` 블록 확인. 타일을 못 찾으면 이 블록을 통째로 복사해서 보내주세요.
4. AI 기록이 **꺼진** 상태에서 **AI 기록 타일 테스트** → 켜지는지, 로그에 `TurnedOn` 이 찍히는지.
5. AI 기록이 **켜진** 상태에서 다시 **AI 기록 타일 테스트** → 꺼지지 않고 `AlreadyOn` 인지.
6. **창 상태 기록(3초 후)** → 누르고 3초 안에 메모 앱(전체 화면/분할/팝업)으로 전환 → 로그의 `판정:` 이 `TARGET_VISIBLE` 인지.
7. 홈의 **자동화 사용** 켜기 → 메모 앱 열기 → AI 기록 켜짐 + "회의 녹음 중" 알림 확인.
8. 메모 앱에서 키보드를 올리고, 알림창을 내렸다 올려보기 → 로그에 "이탈" 이 찍히지 않아야 함.
9. 홈 화면으로 나가서 대기시간(테스트 땐 10초로) 안에 돌아오기 → "종료 타이머 취소".
10. 다시 나가서 대기시간이 지나도록 기다리기 → 녹음 저장 알림.
11. 녹음 중 화면 회전, 화면 잠금/해제, 분할 화면 전환 → 녹음이 계속되는지.
12. 홈 > 최근 녹음 > **회의록 만들기** → ChatGPT에 파일·프롬프트가 들어가는지, 전송이 자동으로 눌리는지. 로그의 `자동전송` 항목을 보내주세요.

## 6. 빌드 (참고)

- PC 없이: 저장소에 푸시하면 GitHub Actions(`.github/workflows/android-apk.yml`)가 APK를 빌드해 **Releases** 에 올립니다. Actions 탭 > Android APK > **Run workflow** 로 수동 실행도 됩니다. (`*.html`, `CNAME` 만 바뀐 푸시는 빌드하지 않습니다 — 같은 저장소의 웹페이지 수정 때문.)
- versionCode = 100 + 실행 번호, versionName = 2.0.실행번호.
- Android Studio: 저장소 폴더를 그대로 열면 됩니다(JDK 17, Gradle wrapper 포함).

### 서명 키 주의
이 저장소는 **공개** 저장소이고 서명 키와 비밀번호가 커밋돼 있습니다. 업데이트 편의를 위한 개인용 설정이며, 이 키로 서명된 APK는 누구나 만들 수 있다는 뜻입니다. 이 저장소의 Releases 외의 경로에서 받은 APK는 설치하지 마세요.
